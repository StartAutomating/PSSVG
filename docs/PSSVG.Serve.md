PSSVG.Serve
-----------

### Synopsis
Serves a request

---

### Description

Serves a single request to PSSVG.

---

### Parameters
#### **Request**
The request to serve

|Type        |Required|Position|PipelineInput|
|------------|--------|--------|-------------|
|`[PSObject]`|false   |1       |false        |

---

### Syntax
```PowerShell
PSSVG.Serve [[-Request] <PSObject>] [<CommonParameters>]
```
