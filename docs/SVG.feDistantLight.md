SVG.feDistantLight
------------------

### Synopsis
Creates SVG feDistantLight elements

---

### Description

The **`<feDistantLight>`** filter primitive defines a distant light source that can be used within a lighting filter primitive: `feDiffuseLighting` or `feSpecularLighting`.
