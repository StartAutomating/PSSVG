PSSVG.HasRoute()
----------------

### Synopsis
Determines if a request has a route.

---

### Description

Determines if a request has a route.

If a route already exists, it returns the route.

If it does not, it attempts to map the route.

---

### Parameters
#### **Request**

|Type      |Required|Position|PipelineInput|
|----------|--------|--------|-------------|
|`[Object]`|false   |1       |false        |
